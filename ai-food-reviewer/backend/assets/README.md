# Optional assets

- `broll/`  - drop vertical or landscape `.mp4` clips here (street footage, food close-ups that **you own or have a licence for**).
  They are auto-cropped to 9:16 and used as scene backgrounds instead of the built-in illustrated scenes.
- `music/`  - drop royalty-free `.mp3` tracks here. If empty, a free procedural background loop is generated automatically.
